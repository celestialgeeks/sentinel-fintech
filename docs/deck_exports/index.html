LangChain-powered NER handles transliteration ("Mohammed Ahmed" ↔ "Mohammed Al-Ahmed"), corporate aliases, name variations. OpenSanctions Pairs: 98.23% F1 vs 95.94% traditional.

Vector Fuzzy Matching

Milvus cosine similarity against OFAC/EU/UN lists. Embeddings via sentence-transformers. Threshold-based alerting with 60% false positive reduction vs exact match.
