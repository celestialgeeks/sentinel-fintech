Slide 09 — Pillar 02

Fraud detection & agentic triage

Two layers: a detection ensemble catches the pattern; an autonomous LLM agent pre-investigates so analysts get dossiers, not raw alerts.

Layer A — Detection

GNN + behavioral + ensemble
  • Behavioral profiling — per-user / per-merchant velocity, deviation, device fingerprint
  • Graph Neural Network on Neo4j — fraud rings, collusion, synthetic identities
  • XGBoost ensemble for tabular fraud signals
  • Sub-200ms inference on streaming transactions
Accuracy · 97.5% (GNN-enhanced) vs 93.2% traditional ML

Layer B — Agentic triage

The differentiator
  • Autonomous LLM agent performs pre-investigation of high-risk alerts
  • Correlates across transactions, devices, IPs, behavioral history, graph neighborhood
  • Hands a summarized risk dossier to the human analyst — not a raw alert

Slide 13 — Closing

Impact, limitations & future work

Honest about what's done, what's open, and where this goes next.

Impact

What this changes

  • Open-source alternative to closed RegTech SaaS (Sardine, Feedzai, Checkmarble)
  • Explainable by design — every alert has a deterministic audit trail, regulator-ready
  • Unified platform solves market fragmentation across AML + Fraud + KYB
  • Production-grade Python/FastAPI codebase, full Docker Compose stack, CI/CD
Limitations

What's open

  • Tested against synthetic + open-source datasets (OFAC, EU sanctions) — not yet on production data
  • LLM calls add latency & cost — needs caching & model distillation for scale
  • GNN training requires labeled fraud-ring data (cold-start challenge)
Future work

Where this goes

  • Real-time streaming inference with Flink + vLLM / Triton
  • Federated learning across institutions without sharing raw data
  • Voice / chat analyst copilot for guided investigation
  • FedRAMP / SOC2 compliance pathway for US enterprise sales
